# NoteSense

A friendly ear trainer that helps you learn to recognise notes by ear, a few minutes a day.
Works on iPhone, Android and desktop as an installable web app.

## Install on iPhone

1. Open **https://drgrey32.github.io/notesense/** in Safari.
2. Tap **⋯**, then **Share**, then **Add to Home Screen**. Keep **Open as Web App** on and tap **Add**.
3. Open NoteSense from the new icon. Always use the icon: it keeps its own progress, separate from Safari.

## Install on Android

Open the link in Chrome, tap the menu, then **Install app**. Long-press the icon for Quick ping and Practice shortcuts.

## What's in this repository

| File | Purpose |
|---|---|
| `index.html` | The whole app: drills, cues, progress, settings |
| `manifest.webmanifest` | Name, icons and shortcuts for home-screen install |
| `sw.js` | Offline support |
| `icon-*.png` | App icons |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

Progress is stored on your device. Use **More → Settings → Back up your progress** to move it between devices.
